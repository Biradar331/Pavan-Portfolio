# Pavan Biradar — Software Engineer Portfolio

Professional placement portfolio built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

## Quick start

See **[SETUP.md](./SETUP.md)** for:
- Adding profile photo & resume
- Running locally
- Full deployment guide (GitHub → Vercel / Netlify)

```bash
npm install
npm run dev
```

## Stack

- React 19 (JavaScript)
- Vite 6
- Tailwind CSS 4
- Framer Motion
- react-icons

## Project structure

```
src/
  components/     # UI sections
  data/           # All portfolio content (edit here)
  hooks/          # Theme toggle
public/
  images/         # Profile & project screenshots
  resume/         # Resume PDF for download
```
